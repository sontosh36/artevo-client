# Artwork Showcase Platform (Artevo)

**Live Site URL:** [https://artevo-art-sharing-platform.web.app]

## description
An artwork showcase platform where users can share, manage and intract with artwork using a modern full stack web application.

---

## features
- user authentication system,
- Users can Add, Update and Delete their own artworks,
- Protected routes for authenticated users,
- Like and Favorite system for artwork,
- Fast and smooth client side navigation using React Router
